## 引言

在数据科学和机器学习领域，我们习惯了处理结构化的表格数据、序列化的时序数据，以及非结构化的图像和文本。然而，现实世界中大量重要问题天然具有图结构——社交网络、知识图谱、分子结构、推荐系统等。**Graph Engineering（图工程）**正是研究如何高效存储、查询、分析和学习图结构数据的工程学科。

本文将由浅入深，从图论基础到图神经网络，再到工程化实践，带你全面了解图计算的世界。

## 第一部分：图论基础

### 什么是图？

图（Graph）是由**节点（Node/Vertex）**和**边（Edge/Link）**组成的数学结构：

```
G = (V, E)
```

其中 V 是节点集合，E 是边集合。

### 图的类型

| 类型 | 描述 | 示例 |
|------|------|------|
| 无向图 | 边没有方向 | 社交好友关系 |
| 有向图 | 边有方向 | 微博关注关系 |
| 加权图 | 边有权重 | 道路距离 |
| 二部图 | 节点分为两组 | 用户-商品关系 |
| 多重图 | 节点间可有多条边 | 多种交互方式 |

### 图的表示

```python

    [1, 0, 0, 0, 0],  # 节点 3 连接到 0
    [0, 1, 0, 0, 0],  # 节点 4 连接到 1
])
```

### 图的基本算法

**BFS（广度优先搜索）**：

```python
from collections import deque

def bfs(graph, start):
    visited = set()
    queue = deque([start])
    visited.add(start)
    
    while queue:
        node = queue.popleft()
        print(node, end=' ')
        
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

# 时间复杂度: O(V + E)
```

**最短路径（Dijkstra）**：

```python
import heapq

def dijkstra(graph, start, weights):
    dist = {node: float('inf') for node in graph}
    dist[start] = 0
    heap = [(0, start)]
    
    while heap:
        d, u = heapq.heappop(heap)
        if d > dist[u]:
            continue
        for v in graph[u]:
            new_dist = d + weights[(u, v)]
            if new_dist < dist[v]:
                dist[v] = new_dist
                heapq.heappush(heap, (new_dist, v))
    
    return dist
```

## 第二部分：图神经网络（GNN）

### 为什么需要 GNN？

传统神经网络（MLP、CNN、RNN）处理的是欧几里得空间的数据，而图数据具有以下特性：

1. **非结构化**：没有固定的空间排列
2. **节点依赖**：节点间存在复杂的连接关系
3. **动态拓扑**：节点和边的数量可能变化

GNN 通过**消息传递机制**来处理这些特性。

### 消息传递框架

GNN 的核心是**消息传递（Message Passing）**：

```
m_i^(t) = AGGREGATE^(t)({ h_j^(t-1) : j ∈ N(i) })
h_i^(t) = UPDATE^(t)(h_i^(t-1), m_i^(t))
```

其中：
- `h_i^(t)` 是节点 i 在第 t 层的表示
- `N(i)` 是节点 i 的邻居集合
- `m_i^(t)` 是聚合的消息
- `AGGREGATE` 和 `UPDATE` 是可学习的函数

### 经典 GNN 模型

**GCN（Graph Convolutional Network）**：

```python
import torch
import torch.nn.functional as F
from torch_geometric.nn import GCNConv

class GCN(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels):
        super().__init__()
        self.conv1 = GCNConv(in_channels, hidden_channels)
        self.conv2 = GCNConv(hidden_channels, out_channels)
    
    def forward(self, x, edge_index):
        # x: 节点特征 [num_nodes, in_channels]
        # edge_index: 边索引 [2, num_edges]
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.5, training=self.training)
        x = self.conv2(x, edge_index)
        return F.log_softmax(x, dim=1)
```

**GraphSAGE**：

```python
from torch_geometric.nn import SAGEConv

class GraphSAGE(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels):
        super().__init__()
        self.conv1 = SAGEConv(in_channels, hidden_channels)
        self.conv2 = SAGEConv(hidden_channels, out_channels)
    
    def forward(self, x, edge_index):
        x = self.conv1(x, edge_index).relu()
        x = self.conv2(x, edge_index)
        return x
```

**GAT（Graph Attention Network）**：

```python
from torch_geometric.nn import GATConv

class GAT(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels, heads=8):
        super().__init__()
        self.conv1 = GATConv(in_channels, hidden_channels, heads=heads)
        self.conv2 = GATConv(hidden_channels * heads, out_channels, heads=1)
    
    def forward(self, x, edge_index):
        x = F.elu(self.conv1(x, edge_index))
        x = self.conv2(x, edge_index)
        return x
```

### PyTorch Geometric 实战

```python
import torch
from torch_geometric.data import Data
from torch_geometric.datasets import Planetoid
from torch_geometric.loader import DataLoader
from torch_geometric.nn import GCNConv, global_mean_pool

# 加载 Cora 数据集
dataset = Planetoid(root='/tmp/Cora', name='Cora')
data = dataset[0]

print(f"数据集: {dataset}")
print(f"节点特征维度: {data.x.shape[1]}")
print(f"类别数: {dataset.num_classes}")

# 定义模型
class GNN(torch.nn.Module):
    def __init__(self, hidden_channels):
        super().__init__()
        self.conv1 = GCNConv(dataset.num_features, hidden_channels)
        self.conv2 = GCNConv(hidden_channels, dataset.num_classes)
    
    def forward(self, x, edge_index, batch=None):
        x = self.conv1(x, edge_index).relu()
        x = self.conv2(x, edge_index)
        return x

# 训练
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = GNN(hidden_channels=64).to(device)
data = data.to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01, weight_decay=5e-4)

def train():
    model.train()
    optimizer.zero_grad()
    out = model(data.x, data.edge_index)
    loss = F.nll_loss(out[data.train_mask], data.y[data.train_mask])
    loss.backward()
    optimizer.step()
    return loss

def test():
    model.eval()
    out = model(data.x, data.edge_index)
    pred = out.argmax(dim=1)
    accs = []
    for mask in [data.train_mask, data.val_mask, data.test_mask]:
        acc = (pred[mask] == data.y[mask]).float().mean()
        accs.append(acc)
    return accs

for epoch in range(1, 201):
    loss = train()
    train_acc, val_acc, test_acc = test()
    if epoch % 50 == 0:
        print(f'Epoch: {epoch:03d}, Loss: {loss:.4f}, '
              f'Train: {train_acc:.4f}, Val: {val_acc:.4f}, Test: {test_acc:.4f}')
```

### DGL 实战

```python
import dgl
import dgl.nn as dglnn
import torch
import torch.nn as nn
import torch.nn.functional as F

class GCN(nn.Module):
    def __init__(self, in_feats, h_feats, num_classes):
        super().__init__()
        self.conv1 = dglnn.GraphConv(in_feats, h_feats)
        self.conv2 = dglnn.GraphConv(h_feats, num_classes)
    
    def forward(self, g, in_feat):
        h = self.conv1(g, in_feat)
        h = F.relu(h)
        h = self.conv2(g, h)
        return h

# 加载数据
from dgl.data import CoraGraphDataset
dataset = CoraGraphDataset()
g = dataset[0]

# 定义和训练模型
model = GCN(g.ndata['feat'].shape[1], 16, dataset.num_classes)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

def train():
    model.train()
    logits = model(g, g.ndata['feat'])
    loss = F.cross_entropy(logits[g.ndata['train_mask']], 
                           g.ndata['label'][g.ndata['train_mask']])
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    return loss

for epoch in range(100):
    loss = train()
    if epoch % 20 == 0:
        print(f'Epoch {epoch}: Loss {loss:.4f}')
```

### 社交网络分析

```python
# 识别影响力用户
def identify_influencers(G, top_k=10):
    pagerank = nx.pagerank(G)
    top_users = sorted(pagerank.items(), key=lambda x: x[1], reverse=True)
    return top_users[:top_k]

# 欺诈检测
def detect_fraud(G, suspicious_threshold=0.1):
    # 基于社区结构的异常检测
    communities = nx.community.greedy_modularity_communities(G)
    for comm in communities:
        subgraph = G.subgraph(comm)
        density = nx.density(subgraph)
        if density < suspicious_threshold:
            return list(comm)
    return []
```

### 推荐系统

```python
import torch
from torch_geometric.nn import LightGCN

class Recommender(torch.nn.Module):
    def __init__(self, num_users, num_items, embedding_dim):
        super().__init__()
        self.user_embedding = torch.nn.Embedding(num_users, embedding_dim)
        self.item_embedding = torch.nn.Embedding(num_items, embedding_dim)
        self.conv = LightGCN(embedding_dim, num_layers=3)
    
    def forward(self, edge_index):
        x = torch.cat([
            self.user_embedding.weight, 
            self.item_embedding.weight
        ])
        return self.conv(x, edge_index)
```

### 3. 调参技巧

```python
# 学习率调度
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
    optimizer, T_max=100, eta_min=1e-6
)

# 早停
class EarlyStopping:
    def __init__(self, patience=10, min_delta=1e-4):
        self.patience = patience
        self.min_delta = min_delta
        self.counter = 0
        self.best_loss = None
        self.should_stop = False
    
    def __call__(self, val_loss):
        if self.best_loss is None or val_loss < self.best_loss - self.min_delta:
            self.best_loss = val_loss
            self.counter = 0
        else:
            self.counter += 1
            if self.counter >= self.patience:
                self.should_stop = True
```

### 4. 避坑清单

1. **内存溢出**：大图全量加载会 OOM，使用 mini-batch 或图采样
2. **过拟合**：小图上 GNN 容易过拟合，使用 dropout 和权重衰减
3. **标签不平衡**：使用加权损失函数或过采样
4. **特征工程**：不要忽略节点特征，纯结构信息有时不够
5. **评估指标**：根据任务选择合适的指标，不要只看准确率
