## 引言

在 Edge Computing 和 Serverless 架构日益流行的今天，传统的 Web 框架（如 Express）面临着新的挑战：它们需要在各种不同的 JavaScript 运行时中工作。Hono 应运而生，它是一个基于 Web 标准构建的超快 Web 框架，可以在 Cloudflare Workers、Deno、Bun、Node.js 等任何支持 Web 标准的运行时中运行。

本文将由浅入深，从理论到实践，带你全面了解 Hono 框架。

## Hono 是什么？

"Hono" 在日语中意为"火焰"，它是一个小巧、简单且超快的 Web 框架。它的核心特点包括：

- **基于 Web 标准**：只使用 Fetch API 等 Web 标准接口
- **跨平台**：同一份代码可以在多个运行时中运行
- **高性能**：在各种基准测试中表现优异
- **轻量级**：核心库非常小巧
- **TypeScript 优先**：提供优秀的类型支持

## 为什么需要 Hono？

### 传统框架的痛点

传统的 Node.js Web 框架（如 Express）存在一些问题：

1. **平台依赖**：深度绑定 Node.js 运行时
2. **性能瓶颈**：在 Serverless 环境中冷启动时间长
3. **标准不统一**：使用自己的 Request/Response 封装，而非 Web 标准

### Hono 的解决方案

Hono 通过以下方式解决了这些问题：

1. **使用 Web 标准 API**：如 `fetch`、`Request`、`Response`、`URL` 等
2. **零依赖**：核心库不依赖任何外部包
3. **统一接口**：在所有平台提供一致的开发体验

## 快速开始

### 安装

使用 `create-hono` 命令创建新项目：

```bash
# npm
npm create hono@latest my-app

# yarn
yarn create hono my-app

# pnpm
pnpm create hono@latest my-app

# bun
bun create hono@latest my-app
```

然后选择你需要的平台模板（如 `cloudflare-workers`、`nodejs` 等）。

### Hello World

创建完成后，在 `src/index.ts` 中编写你的第一个应用：

```typescript
import { Hono } from 'hono'

const app = new Hono()

app.get('/', (c) => {
  return c.text('Hello Hono!')
})

export default app
```

运行开发服务器：

```bash
npm run dev
```

访问 `http://localhost:8787` 即可看到结果。

## 核心概念

### Context 对象

`c` 参数是 Hono 的 Context 对象，它封装了请求和响应的处理方法：

```typescript
app.get('/example', (c) => {
  // 获取请求信息
  const url = c.req.url
  const method = c.req.method
  const headers = c.req.header()
  const query = c.req.query('key')
  const param = c.req.param('id')
  
  // 设置响应
  c.header('X-Custom', 'value')
  c.status(200)
  
  // 返回不同类型的响应
  return c.text('text')
  return c.json({ data: 'json' })
  return c.html('<h1>HTML</h1>')
  return c.redirect('/new-location')
})
```

## 中间件系统

Hono 采用洋葱模型的中间件系统，执行顺序如下：

```
Request → 中间件1 → 中间件2 → Handler → 中间件2 → 中间件1 → Response
```

### 基本中间件

```typescript
// 日志中间件
app.use(async (c, next) => {
  const start = Date.now()
  await next()
  const ms = Date.now() - start
  console.log(`${c.req.method} ${c.req.path} - ${ms}ms`)
})

// 添加响应头
app.use('*', async (c, next) => {
  await next()
  c.res.headers.set('X-Response-Time', `${Date.now()}ms`)
})
```

### 路径特定中间件

```typescript
// 只对特定路径生效
app.use('/admin/*', basicAuth({
  username: 'admin',
  password: 'secret',
}))

// 多个路径
app.use(['/api/*', '/admin/*'], authMiddleware)
```

### 内置中间件

Hono 提供了丰富的内置中间件：

```typescript
import { cors } from 'hono/cors'
```

## 实战：构建 RESTful API

让我们构建一个简单的文章管理 API：

```typescript
import { Hono } from 'hono'
import { cors } from 'hono/cors'
import { logger } from 'hono/logger'

const app = new Hono()

// 全局中间件
app.use('*', logger())
app.use('*', cors())

// 内存存储
interface Post {
  id: number
  title: string
  content: string
}

let posts: Post[] = []
let nextId = 1

// 获取所有文章
app.get('/posts', (c) => {
  return c.json(posts)
})

// 获取单篇文章
app.get('/posts/:id', (c) => {
  const id = parseInt(c.req.param('id'))
  const post = posts.find(p => p.id === id)
  
  if (!post) {
    return c.json({ error: 'Post not found' }, 404)
  }
  
  return c.json(post)
})

// 创建文章
app.post('/posts', async (c) => {
  const body = await c.req.json()
  const post: Post = {
    id: nextId++,
    title: body.title,
    content: body.content,
  }
  
  posts.push(post)
  return c.json(post, 201)
})

// 更新文章
app.put('/posts/:id', async (c) => {
  const id = parseInt(c.req.param('id'))
  const index = posts.findIndex(p => p.id === id)
  
  if (index === -1) {
    return c.json({ error: 'Post not found' }, 404)
  }
  
  const body = await c.req.json()
  posts[index] = { ...posts[index], ...body }
  
  return c.json(posts[index])
})

// 删除文章
app.delete('/posts/:id', (c) => {
  const id = parseInt(c.req.param('id'))
  const index = posts.findIndex(p => p.id === id)
  
  if (index === -1) {
    return c.json({ error: 'Post not found' }, 404)
  }
  
  posts.splice(index, 1)
  return c.text('Deleted', 200)
})

export default app
```
