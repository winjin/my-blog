## 引言

Figmimic是一款书签工具（bookmarklet），可以将任何网页复制为Figma中可编辑的图层。对于设计师来说，这可能是最实用的生产力工具之一。

## 什么是书签工具？

书签工具是一段保存在浏览器书签栏中的JavaScript代码，点击后可以：

- 修改当前页面的样式
- 提取页面内容
- 执行自定义操作

```
书签工具 = 浏览器中的快捷方式
```

## Figmimic的工作原理

### 1. 页面解析

```javascript
// 伪代码示意
function parsePage() {
  const elements = document.querySelectorAll('*');
  const layers = [];
  
  elements.forEach(el => {
    layers.push({
      tag: el.tagName,
      text: el.textContent,
      styles: getComputedStyle(el),
      position: el.getBoundingClientRect()
    });
  });
  
  return layers;
}
```

### 2. 图层转换

```
HTML元素 → Figma图层
├── div → Frame
├── h1-h6 → Text
├── p → Text
├── img → Image
├── button → Component
└── form → Frame
```

### 3. 样式映射

```css
/* CSS属性 → Figma属性 */
font-size → fontSize
color → fills
padding → padding
border-radius → cornerRadius
box-shadow → effects
```

## 技术实现

### 安装书签工具

```javascript
// 书签工具代码（简化版）
javascript:void(function(){
  var elements = document.querySelectorAll('*');
  var layers = [];
  
  elements.forEach(function(el){
    var rect = el.getBoundingClientRect();
    layers.push({
      type: el.tagName,
      text: el.innerText,
      x: rect.x,
      y: rect.y,
      width: rect.width,
      height: rect.height,
      styles: window.getComputedStyle(el)
    });
  });
  
  // 复制到剪贴板
  copyToClipboard(JSON.stringify(layers));
}());
```

## 实际效果

### 优点

1. **节省时间**：从几小时到几分钟
2. **准确还原**：精确匹配原始设计
3. **可编辑性**：所有元素都可修改
4. **无需插件**：纯浏览器实现

### 局限性

```
可能的问题:
├── 复杂动画无法复制
├── 动态内容需要手动处理
├── 某些CSS属性不支持
└── 需要网络连接
```

## 避坑清单

| 问题 | 原因 | 解决方案 |
|-----|------|---------|
| 复制不完整 | 页面动态加载 | 等待页面完全加载 |
| 样式丢失 | 不支持的CSS | 手动调整 |
| 图层混乱 | 复杂布局 | 简化页面结构 |
| Figma卡顿 | 图层过多 | 分批复制 |

## 总结

Figmimic展示了**简单工具解决复杂问题**的哲学：

1. **最小化干预**：只做一件事，但做得很好
2. **用户友好**：一键操作，无需学习
3. **实用主义**：解决真实的设计痛点

**给设计师的建议：**

1. 将Figmimic添加到你的书签栏
